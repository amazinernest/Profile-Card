# Profile Card (Vanilla)

A simple, accessible profile card built with vanilla HTML, CSS, and JavaScript.

## Getting started

Just open `index.html` in any modern web browser.

## structure

- `index.html`: contains the semantic structure and data-testid attributes.
- `style.css`: handle layout and themes.
- `script.js`: live epoch time logic.
- `avatar.png`: profile image.

## data-testid attributes

| Element | testid |
|---|---|
| Card root | `test-profile-card` |
| Name | `test-user-name` |
| Bio | `test-user-bio` |
| Epoch time | `test-user-time` |
| Avatar | `test-user-avatar` |
| Social links wrapper | `test-user-social-links` |
| Hobbies list | `test-user-hobbies` |
| Dislikes list | `test-user-dislikes` |

## Notes

- semantic tags: `article`, `header`, `figure`, `nav`, `section`
- keyboard accessible social links
- mobile-first responsive design
- no build tools or frameworks required
